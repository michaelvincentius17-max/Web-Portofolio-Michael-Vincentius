## 💻 Cara Menjalankan Secara Lokal

1. **Clone repository ini:**
   ```bash
   git clone https://github.com/michaelvincentius17-max/web-portfolio.git
   cd web-portfolio
   ```

2. **Jalankan server lokal (Node.js):**
   ```bash
   node server.js
   ```
   Buka browser di `http://localhost:3000`.

3. **Atau buka langsung file `index.html`** dengan browser apa saja tanpa instalasi tambahan.

---

## 🌐 Menayangkan di GitHub Pages (Gratis)

1. Buka repository Anda di GitHub: `https://github.com/michaelvincentius17-max/web-portfolio`.
2. Masuk ke tab **Settings** > **Pages**.
3. Pada bagian **Build and deployment** > **Source**, pilih **Deploy from a branch**.
4. Pilih branch `main` (atau `master`) dan folder `/ (root)`, lalu klik **Save**.
5. Website portofolio Anda akan otomatis online di:  
   `https://michaelvincentius17-max.github.io/web-portfolio/`
